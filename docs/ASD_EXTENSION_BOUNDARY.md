# ASD Extension Boundary

Status: **OUT OF SCOPE; NO ASD REPOSITORY OR DATA MODIFIED**

1. ASD/Control diagnosis is a subject-level between-subject variable.
2. Each subject has exactly one diagnosis. A subject-by-diagnosis conditional interaction is therefore not identifiable within subject.
3. Resting-state ASD windows must not be assigned arbitrary pseudo-classes to manufacture a subject×class design.
4. A valid extension requires a within-subject condition `c` experienced by every subject, such as a common stimulus or task condition.
5. In that design, construct `Z[s,q,c]` first using only the common within-subject conditions. Then test, with subject-level inference, whether the distribution of held-out latent coordinates `alpha_s` differs by diagnosis group.
6. That analysis is not a replication of the present motor-imagery experiment. It is a separate hierarchical clinical EEG question with its own confounding, sampling, group-balance, and multiplicity protocol.
7. This branch does not execute Rogala, Sheffield, or any other ASD dataset and does not modify any ASD repository, loader, cache, output, or raw data.

No ASD biomarker, diagnosis, clinical utility, or patient-level prediction claim can be derived from Subject-Class Population Structure V1.
