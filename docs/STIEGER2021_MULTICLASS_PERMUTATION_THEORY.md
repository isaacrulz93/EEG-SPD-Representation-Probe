# Stieger2021 Multiclass Permutation Theory

An unlabeled four-component target mixture is invariant under every permutation of its semantic component names. Therefore an intrinsic signed or named semantic coordinate is not identifiable from pooled target observations alone: the ambiguity group is the full symmetric group (S_4), not four independent binary signs.

This experiment introduces a declared external structural assumption: source and target preserve the literal semantic class correspondence in a fixed, source-derived latent coordinate system. The test does not rotate, reflect, tune, or relabel the target representation. It removes target row labels, enumerates all 24 row permutations, and compares each to the centered unit-Frobenius source template by a frozen squared-Frobenius cost. The literal identity mapping succeeds only when it is the unique minimum; ties fail.

Target class labels are used only after the target centroids and all 24 costs are saved, to reveal which anonymous row corresponds to the literal class. Success is evidence for the explicit source-template preservation assumption in this prospective dataset. It is not intrinsic zero-label identifiability and does not eliminate the mathematical permutation invariance.
