## Audit conclusion

The novelty candidate is not "using an SPD sequence for the first time."

The exact remaining bridge is: does pre-cue baseline-relative local geometry
increase identifiability of zero-label class correspondence or a
class-independent subject nuisance action?

The present branch may continue only on that bridge. It must not introduce an
SPDHSW loss, target pseudo-labeling, a domain-conditioned canonicalizer, or a
large sequence model to rescue a negative linear result.
