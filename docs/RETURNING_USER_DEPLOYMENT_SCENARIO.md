# Returning-User Deployment Scenario

The user first completes an **initial calibration** in a labeled enrollment
session. Population-development subjects, not the held-out user, determine the
session map and every hyperparameter. At a later deployment session the method
receives no new task labels. It may translate predicted centered class prototypes
by the mean of the frozen deployment tangent trial batch, which is the declared
unlabeled session-wise marginal alignment.

Thus the precise claim under test is **zero-recalibration for a returning user
after one labeled enrollment session**. The evaluation is offline and batched.
It is neither new-user zero calibration nor a causal online adapter.
