# Interpretation Boundaries: Subject Location → Conditional Configuration V0

This experiment tests one held-out-subject association: whether label-free
SPD location in one session predicts class-centered subject×class deformation
in the other session.

A GO result would support only the viability of that geometric location as a
predictor of cross-session conditional deformation. It would not establish a
deployable TTA method, identify target class semantics, improve a classifier,
recover a conditional density, identify a causal or physiological subject
factor, or generalize to ASD or unrelated datasets.

A weak result means that some association exists but is not sufficiently
material, direction-consistent, or influence-stable for method development.
A STOP result means only that the registered full-covariance Stieger task-3
location failed this specific cross-session prediction criterion. Subject
identity or marginal repeatability is not a substitute for conditional
prediction.

The same-session control is deliberately non-voting because input and outcome
can share session-specific noise. The all-subject reference is post-hoc only.
Class and session labels are never features. Target outcomes are opened only
after immutable prediction hashes exist.

No subject-conditioned classifier, prototype shift, bilinear modulation, SPD
layer conditioning, TTA, neural network, temporal model, or follow-up
experiment is part of V0. The exact next question is recorded after the
terminal but is not executed.
